# Reconocimiento de gestos
> ### Reconocimiento de gestos desde una perspectiva egocéntrica.

## Demostración
![demo](https://github.com/zzeitt/Gesture-Recognition/blob/master/demo.gif)

## Estructura
* Seguimiento de manos (de [victordibia](https://github.com/victordibia/handtracking))
* Estimación de gestos (usando métodos tradicionales de procesamiento de imágenes)

## Requisitos
* python 3.5.6
* paquetes principales:
    - numpy
    - opencv-python
    - tensorflow
    - multiprocessing (incluido)
